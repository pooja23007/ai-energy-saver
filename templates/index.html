How this system works

1. IoT analytics
Reads smart-plug readings for each appliance and finds power used while nobody is home.
2. ML forecasting
A Random Forest learns usage patterns and predicts the next 24 hours.
3. AI recommendations
Combines the waste found and the forecast to tell the user what to change and how much they save.
